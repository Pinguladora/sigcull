# Decision records

These are the architecture decision records (ADRs) that shaped sigcull. They are
kept alongside the code in [`docs/adr`](https://github.com/Pinguladora/sigcull/tree/main/docs/adr)
and surfaced here unchanged, so the reasoning behind the verifier, the trust
model, and the signature authorities stays with the documentation.

Each record states the context, the decision, and its consequences at the time
it was made. Superseded records are kept for the history, not edited away.
