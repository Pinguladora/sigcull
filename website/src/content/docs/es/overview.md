sigcull es una GitHub App que verifica la firma de cada commit y convierte el
resultado en un Check Run obligatorio, de modo que los commits sin firmar o no
autorizados no puedan fusionarse en una rama protegida. Funciona en repositorios
privados y contra cualquier instancia de Sigstore.

Empieza por [Primeros pasos](/es/getting-started/) para tu primer
commit firmado y, a continuación, consulta:

- [Autoridades](/es/authorities/) para los formatos de firma que acepta sigcull.
- [Configuración](/es/configuration/) para la referencia completa de la política.
- [Fuentes de confianza](/es/trust-sources/) para raíces public, TUF y estáticas.
- [Despliegue](/es/deployment/) para ejecutar la App.
- [Modelo de seguridad](/es/security-model/) para los límites de confianza.
